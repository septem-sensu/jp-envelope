view.php : 20

This class represents a configured view (views.json): it binds a view method to a business class, carries the result type (empty = HTML, 'json' = JSON response), the template chain and the allowed role ids, and executes the actions and the view method of the view.

validateActions()  : void
This method validates the action entries of the view (objects with a "method" field plus exactly one routing field, see the actionNames property) fail-loud: the entry must be an object with a valid "Class::method" that exists in the class code, and either a string "trigger" or a true "always" — neither both nor none. Config drift (a renamed or removed method, an ambiguous routing declaration) would otherwise die silently.
validatePermissions()  : void
This method validates the permission entries of the role ("Class::method") fail-loud against the class code: the class and the method must exist, the entry must consist of exactly two segments. Config drift (a renamed or removed method) would otherwise die silently — a permission that no action ever matches again. The RuntimeException lands via the executeActions catch of execute() in the soft error channel + server log.

view.php : 272

This method validates the permission entries of the role ("Class::method") fail-loud against the class code: the class and the method must exist, the entry must consist of exactly two segments. Config drift (a renamed or removed method) would otherwise die silently — a permission that no action ever matches again.
