in package
  • Application

controller.php : 35

This class is the front controller of the app.

index.php instantiates it and calls execute(). The constructor resolves the auth context (user, role), the view (views.json configuration with the permission guard) and the request scope; execute() then runs the view actions, collects the soft errors of the actions into the AppError channel, throws the business objects into the frontend collector and returns the rendered HTML or the json payload. Hard errors are caught granularly: an action crash lands in the soft error channel with generic text, a view crash leads to the emergency page with HTTP 500.

init()  : void
This method resolves the request context. It creates the user (auth resolution order), the presentation and the role, resolves the view from the view parameter (a view the role has no permission for — or an unknown view — silently falls back to the role's default view) and sets the request scope to the view.
