UserCollection extends BaseCollection
in package
  • Application

userCollection.php : 20

This class is the typed collection over User business objects: it declares User as the allowed element type of BaseCollection and inherits the container behavior from it.

Methods

clear()  : void
This method removes all elements of the collection.
count()  : int
This method is the Countable implementation: it returns the number of elements of the collection, so that a collection instance is usable with the count() function.
getAll()  : array<string|int, mixed>
This method returns the elements of the collection as an array, in their insertion order. For the fillObject()/rawObject() pair it is the single read route onto the container content.
getAllowedType()  : string
This method declares the allowed element type of the collection.
getIterator()  : Traversable
This method is the IteratorAggregate implementation: it returns an iterator over the collection elements, so that every collection instance is usable in foreach loops.
idArray()  : array<string|int, mixed>
This method returns the ids of the collection elements as an array, in their insertion order. It is the id-list read route of the persistence contract: serializeObjectForSave() stores collection properties as this list and rawObject() reports it as the value of the collection descriptor.
pop()  : mixed
This method removes the last element of the collection and returns it (null when the collection is empty).
push()  : void
This method appends one element or multiple elements at the end of the collection. Non-array input is taken as a single element, array input is appended element by element in the given order. Every element must be an instance of getAllowedType(), otherwise an InvalidArgumentException is thrown; elements appended before the mismatch stay in place.
set()  : void
This method replaces the complete collection content: it clears the current elements and appends the given ones via push() (with the same type validation, single element or array).
shift()  : mixed
This method removes the first element of the collection and returns it (null when the collection is empty).
unshift()  : void
This method prepends one element or multiple elements at the front of the collection. Non-array input is taken as a single element, array input is prepended as a whole, preserving its order (the iteration over the reversed array). Every element must be an instance of getAllowedType(), otherwise an InvalidArgumentException is thrown; elements prepended before the mismatch stay in place.
