request.php : 23

This class is the single access point for GET and POST parameters.

Raw access to $_GET/$_POST is forbidden outside this class. Validation rules (type, whitelist, pattern, default) are declared declaratively in json/data/params.json — one branch per view plus the 'global' branch for everything before the view resolution (auth, view, id, class). Undeclared parameters do not exist (fail-closed, silent); a misconfigured params.json on the other hand fails loudly.
