FieldValidator
in package
  • Application

fieldValidator.php : 31

This class is the server side counterpart of the frontend fieldValidator.js: it validates request values against the form field definitions of a business class (includes/json/fields/{klasseKlein}.json) — the same single source of truth the frontend uses. Actions call validate() with the class name and an optional fieldset: without a fieldset every declared field is validated with its own mandatory flag (the create case), with a fieldset only the listed fields run — bare entries stay mandatory, boolean entries downgrade the field to optional. The method reports instead of aborting: it returns the first error message per field (field name => message), so actions can collect soft errors via addError() and keep their partial save semantics. Domain guards (existence, permissions, ownership) deliberately stay in the actions.

Methods

validate()  : array<string|int, mixed>
This method validates the request values of a class against its form field definitions. Without a fieldset every declared field runs with its own mandatory attribute; with a fieldset only the listed fields run — a bare entry (numeric key) stays mandatory, an entry with a string key takes the boolean value as its mandatory flag. Fields without a definition are skipped silently. It returns the first error message per failed field (field name => message), an empty array means every value is valid.
message()  : string
This method builds the error message of a rule: the per field override from the messages entry of the field definition wins over the class template. The placeholder {field} is replaced by the nameDe attribute (fallback: the field name), all other placeholders by the given rule parameters (e.g. {minLength}).
validateField()  : string|null
This method validates the request values of a single field against its field definition and returns the first error message or null. The rule cascade mirrors the frontend order: absence, password companion (the {field}2 parameter), match, minlength, password security, select options, mail. Optional password fields only run when the request carries the field or its companion.
validatePassword()  : bool
This static method validates a password against the password rules from configs.json: minimum length and the required character groups (capital letters, lowercase letters, numbers, special characters).
