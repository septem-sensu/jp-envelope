Class: App

App

This class is the central app context: it travels as envelope (class 'App', id {appAlias}_{version}) at position 1 of the collector and carries currentUserId, currentUserRoleId and the serialized view in its data payload — the replacement of the former header variables. As the only class on every view it owns the central error display (showAppErrors), the JS error channel (reportError incl. window.onerror) and the blueprint route (newObject).

new App()

This method is the constructor of the class: it wires the global registry and the error counter. The error channel is app-wide and central: the App is loaded on every view, therefore it takes the display of every AppError instance — no template needs own error code. It uses onAppReady instead of a direct call, because the registry is the interface only after the complete registration (events instead of order).

<async> loadResources()

This method loads appError.js itself: the Loader loads classes only on envelope demand, but the JS error channel needs the class guaranteed before window.onerror is applicable. The promise dedupe in the Loader makes double loads harmless. It registers window.onerror only after the load — the resource readiness travels via the loadResources promise the Loader awaits.
Returns:
Type
Promise.<void>
Example
await app.loadResources();

<async> newObject(newClass)

This method demands a blueprint on demand: it loads an empty instance of the class over the view viewNewObject and registers it under the id 'new' — templates access the finished instance over registry.onReady( className, 'new', ... ) (with replay, timing irrelevant). Every disturbance runs over the JS error channel as overlay instead of as silent silence.

reportError(error, source)

This method reports a JS error over the error channel: the frontend stays generic (leak shielding analogous to the PHP channel), full details only into the console. Total method: the catch never re-throws — console.error triggers no window.onerror, so an exception in the error channel (e.g. from showError) stops the recursion. Own id space errorjs{N}: the PHP envelope ids error{N} would otherwise overwrite a JS error silently in the register phase.
Parameters:
Name Type Description
error * The occurred error (Error object or message text)
source string The origin description of the error
Returns:

void
Example
app.reportError( error, 'newObject: User' );
