Class: User

User

This class is the frontend instance of a user: it carries the user data (without password hash — NOSERIALIZE on the PHP side) and owns its form fieldValidator through the BaseObject. It builds the top navbar of every view: app name, role-dependent menu entries and the mobile burger toggle.

new User()

This method is the constructor of the class: it wires only the BaseObject base — the user data arrives as envelope (fillObject).

Methods

addNavbarItem(itemName, itemLink, itemList, funct)

This method appends a menu entry to a navbar list: as li with a link, with optional click callback.
Parameters:
Name Type Default Description
itemName string The visible name of the menu entry
itemLink string The link target of the menu entry
itemList object The list element (or its DOM id as string)
funct function null The optional click callback on the link
Returns:
Type
void
Example
user.addNavbarItem( 'Dashboard', 'index.php?view=viewUserList', itemList );

addNavbarTop()

This method builds the top navbar: app name, the mobile burger toggle and the menu item list. The burger carries role="button" and aria-expanded as screen-reader state, Enter and Space toggle the menu like a real button. Runs only when the page carries the '#navbar-top' container.
Returns:
Type
void
Example
user.addNavbarTop();

addNavbarTopItems()

This method fills the navbar menu: Dashboard and Logout for every user, the user administration entry only for administrators.
Returns:
Type
void
Example
user.addNavbarTopItems();
