Class: Registry

Registry

This class is the instance layer of the frontend: a map of maps — class name (lower case) → (id → instance). The Loader registers the finished instances, templates never read them directly but wait for the registry events (ready per id, class-wide per instance, appReady once) — already fired events replay for late listeners, class-wide listeners subscribe permanently, the timing stays decoupled from the load order.

new Registry()

This method is the constructor of the class: it carries the registry map (class name → instance map), the ready listeners and the fired event store (replay base — class-wide ready events hold an instance map instead of a single value).

onAppReady(callback)

This method registers an onAppReady callback: already fired events dispatch directly with the app instance (replay), otherwise the callback waits for the Loader. Templates use this as the entry hook instead of running directly after the instantiation.

onReady(className, id, callback)

This method registers a ready listener in two modes: with id an one-time delivery — an already fired event dispatches the callback directly (replay), the callback is not stored; with id null a permanent per-instance subscription of the class — the replay dispatches the callback for every already registered instance, the callback stays armed for later registrations (e. g. on-demand envelopes after appReady). Blueprints never arrive class-wide: templates which need them listen on onReady( className, 'new' ).
Parameters:
Name Type Default Description
className string The PHP class name
id string | null null The instance id or null for the class-wide subscription
callback function The callback with the instance as parameter
Returns:
Type
void
Examples
registry.onReady( 'User', 'new', ( blueprint ) => { ... } );
registry.onReady( 'User', null, ( instance ) => { ... } );

register(className, id, instance)

This method registers an instance under class name and id and fires the ready events in order: the instance event ready:{class}:{id} first, afterwards the class-wide event ready:{class} for every class-wide listener (blueprints keep silent class-wide — the blueprint onReady path stays the dedicated route). Earlier registered listeners dispatch directly, later ones are served from the replay over firedEvents.
Parameters:
Name Type Description
className string The PHP class name of the envelope
id string The instance id (registry key)
instance object The finished instance
Returns:
Type
void
Example
registry.register( 'User', 'max@musterman.de', instance );

setAppReady()

This method marks the app as ready — the Loader calls it once after the complete bootstrap (all resources awaited, all instances registered) and dispatches the stored onAppReady callbacks with the app instance.

void
