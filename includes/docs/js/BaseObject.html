Class: BaseObject

BaseObject

This class is the JavaScript base class of every business class: it carries the envelope data (fillObject), delivers the default getter/setter pair, clones templates with suffixed DOM ids into the page (multi-instance cards), owns the default resource loader and hosts the global click/Enter delegation for the CRUD forms as well as the persistent overlay of the JS error channel. The server counterpart is the PHP BaseObject — every business object arrives as envelope (class, id, data) through the collector and the Loader instantiates it from this family.

new BaseObject()

This method is the constructor of the class: it wires the own fieldValidator, the global loader/config references, the debug flag and registers the global event handlers exactly once per page load.

appendTemplate(templateId, targetId, setId)

This method clones the content of a template element into the target container. With setId it suffixes every id and for attribute with '-' + validateId( this.id ) — parallel instance cards stay addressable over unique DOM ids (CSS selectors). The template content lives in an own document fragment: DOM queries must run after this append, not before.
Parameters:
Name Type Default Description
templateId string The DOM id of the template element
targetId string The DOM id of the target container
setId boolean true True to suffix the ids (default true)
Returns:
Type
void
Example
instance.appendTemplate( 'user-form-template', 'user-cards', true );

<async> loadResources()

This method is the default resource loader: it resolves immediately — the resource readiness travels only via the loadResources promise (the Loader awaits it) and the registry ready events. Classes with own resources (Chart.js, stylesheets) overwrite it and await their own loads — the Loader calls it after the instantiation and awaits it before the instance registers.

validateId(id)

This method escapes an instance id into a DOM and CSS safe form: '@' becomes _at_, '.' becomes _dot_, whitespace becomes '-' and every remaining special character '_' — user ids are e-mail addresses and the suffixes end in CSS selectors (#form-...).
Parameters:
Name Type Description
id string The raw instance id
Returns:
id The DOM safe id fragment
Type
string
Example
