Members

globalRegisteredEvents :Object.<string, boolean>

Global, static register to avoid multiple registrations of event handlers. Prevents double bindings, even with multiple class instances.
Type:
  • Object.<string, boolean>
Example
if( Utils.globalRegisteredEvents[ 'Gameplay' ] ) return;
Utils.globalRegisteredEvents[ 'Gameplay' ] = true;
