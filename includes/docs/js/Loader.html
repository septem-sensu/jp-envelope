Class: Loader

Loader

This class is the dynamic half of the frontend bootstrap: the header loads only the base scripts statically (utils, loader, registry, fieldValidator, BaseObject) — every view class, Chart.js and every stylesheet is requested by the Loader on demand (one class per file, file name = first letter lower case CamelCase). registerObjects() builds the complete bootstrap from the injected collector: per envelope one instance, then all resources awaited, then the registry entries, then app-ready — all-or-nothing; only without debug the rawObjects leave the namespace, a failed resource load keeps them (fail-loud). Every route registers with its event type (registerObjects: load, loadNewObject: new, loadObject: load, saveObject: save, deleteObject: delete) — the registry fires the matching object events beside ready.

new Loader()

This method is the constructor of the class: it carries the promise dedupe map for script and stylesheet loads (key: file name).

<async> deleteObject(className, id)

This method deletes an addressed object over the generic json delete route (viewDeleteObject, POST): the parameters class and id travel as urlencoded body. The response envelopes register with the 'delete' event type (onDelete beside ready); the empty success response removes the registry instance — remove cleans every replay trace of the id. AppError envelopes display in the overlay afterwards. Errors (HTML answer at a wrong role, empty 500 body, network) tear the promise up, the catch sits in the app wrapper (overlay).

registerObjects()

This method builds the complete app bootstrap: it instantiates every envelope of the collector in parallel, awaits afterwards all loadResources() calls, registers the finished instances in the registry and fires app-ready only then. Without debug it deletes the rawObjects from the namespace afterwards — a failed resource load keeps them (fail-loud).
Returns:
Type
void
Example
loader.registerObjects();

<async> saveObject(rawObject)

This method saves an envelope over the generic json save route (viewSaveObject, POST): the envelope (class, id, data) travels as the urlencoded 'object' parameter — with the blueprint id the server creates the object under a generated id. The response envelopes run through the standard pipeline (instantiateRawObjects) and register with the 'save' event type (onSave beside ready): object envelopes register/refresh their registry instances, AppError envelopes display in the overlay afterwards. On a successful blueprint save the stale blueprint instance leaves the registry — the server id replaced it. Errors (HTML answer at a wrong role, empty 500 body, network) tear the promise up, the catch sits in the app wrapper (overlay).
Parameters:
Name Type Description
rawObject object The envelope (class, id, data) to save
Returns:
instances The registered instances of the response (saved object or AppError cards)
Type
Promise
Example
await loader.saveObject( { class: 'User', id: 'new', data: { ... } } );
