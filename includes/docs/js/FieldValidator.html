Class: FieldValidator

FieldValidator

This class represents the FieldValidator class with all properties and methods. The FieldValidator class validates input fields as well as passwords and email addresses and throws form errors if necessary. If a button with CSS class "submit", "save" or "new" is present in a form, it will be disabled or enabled.

This method goes through all the input fields of a form and adds three to each input field added event handler. One when changing the input field, one when leaving the input field and one when pressing a key in the input field.
