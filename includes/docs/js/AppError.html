Class: AppError

AppError

This class is a frontend error card: message, severity ('error' | 'warning') and source travel as properties, the display runs as DOM card over the overlay of the BaseObject. The PHP channel delivers the envelopes (ids error{N}), the JS channel registers its own instances (ids errorjs{N}). Deliberately not named Error: Error is a built-in in PHP (Throwable base) as well as in JavaScript (window.Error).

new AppError()

This method is the constructor of the class: it wires only the BaseObject base (fieldValidator, loader/config references, global event handlers).
